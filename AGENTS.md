# Установка StripeStudio для пользователя

Это исходники локального инструмента. Не устанавливайте службу и не оставляйте сервер фоном. Не меняйте настройки безопасности Windows для обхода блокировок.

1. Убедитесь, что доступны Python 3.10+ (предпочтительно 3.12), FFmpeg и FFprobe. Проверяйте фактический запуск `python --version`, `ffmpeg -version`, `ffprobe -version`. При отсутствии установите зависимости из официальных источников с учётом политики компьютера. При блокировке Application Control сообщите причину, не отключайте защиту.
2. Из корня клона выполните `powershell -File .\install.ps1`. Можно задать `-InstallDir "D:\Apps\StripeStudio"`. Скрипт создаёт отдельное Python-окружение, пользовательский PATH, ярлыки на рабочем столе и в меню Пуск. Права администратора не нужны. Не перезаписывайте другую установку без проверки её содержимого; пользовательские `user-data` и `exports` сохраняются.
3. В новом терминале проверьте `StripeStudio --version` и `StripeStudio --help`. Выполните короткий рендер с assets/demo-photo.png и assets/demo-video.mp4: `StripeStudio render --photo "assets/demo-photo.png" --video "assets/demo-video.mp4" --out "smoke.mp4" --width 360 --height 640 --duration 1`. Убедитесь, что MP4 создан. Проверьте ярлык GUI, затем остановите его процесс после проверки.
4. Передайте пользователю команды из README. CLI завершается после рендера; `serve` нужен только на время работы GUI/API. FFmpeg должен оставаться доступен в PATH в следующих сессиях.

## Поведение, которое нужно сохранить

- Цветные полосы — исходное статичное фото. Видеополосы — 80% чёрно-белого видео и 20% того же цветного фото.
- Период 34 px при короткой стороне 1080 px; доля видеополос 42%. Ширина видеополос и промежутки постоянны, irregularity=0.
- Все полосы параллельны. Один общий угол выбирается случайно от -80° до +80° на каждую генерацию. Не рандомизировать каждую полосу отдельно.
- По умолчанию 1080×1920, 30 fps, исходный звук. `--angle` фиксирует угол, `--video-opacity` меняет долю видео.
- Рендер автоматически предпочитает NVIDIA NVENC после пробного кодирования. Без совместимого GPU/драйвера/FFmpeg используется CPU. `--encoder cpu` и `--encoder nvenc` задают режим явно. Неподвижное фото и альфа-маска готовятся один раз; общий угол и геометрия не меняются. Результат CLI/API сообщает фактический encoder.
- HTTP API слушает только localhost, POST требуют X-Template-Token. Токен текущего сервера в user-data/session.json; не публикуйте его.

Не коммитьте пользовательские фото/видео, экспорты, session.json, окружения и бинарные сборки. В assets только синтетические демонстрационные файлы.

## Пакетный режим (1.3+)

`batch --photos DIR --videos DIR --out DIR` обрабатывает декартово произведение, без просмотра видео. Нарезка только по `--split`: порог `--split-threshold 15`, строгое ограничение части `--max-part-seconds 10`. Не сохраняет длинную версию, исходные медиа не удаляет. Все части пары имеют один угол. Очищает метаданные всех экспортов. Конфликты имён прерывают запуск без перезаписи. API и пример описаны в README. Проверки на синтетике: `python -m unittest -v test_render test_batch`.
